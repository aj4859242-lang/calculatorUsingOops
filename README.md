

#  Calculator uisng OOP in C++

A simple Calculator project built using **C++** and **Object-Oriented Programming (OOP)** concepts.

This project performs:

- Addition
- Subtraction
- Multiplication
- Division

through a menu-driven interface.


# Features

✅ Menu Driven Program  
✅ Uses Classes and Objects  
✅ Infinite Loop Operations  
✅ Division by Zero Handling  
✅ Beginner Friendly  
✅ Clean and Simple Code Structure  



#  Technologies Used(Basic)

- C++
- Object Oriented Programming (OOP)
- VS Code
- Git & GitHub

#  How to Run

## Step 1 — Compile

```bash
g++ calculator.cpp -o calculator
```

## Step 2 — Execute

### Windows

```bash
./calculator
```

### Linux / Mac

```bash
./calculator
```
